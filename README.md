## Selected work

Most of this was built inside companies and can't be open-sourced, so the portfolio site
carries the screenshots and walkthroughs. Short version:

**Cloud Exhibition — 3D digital twin platform** · Babylon.js · Vue 3 · TypeScript
A multi-user 3D exhibition environment. I owned the front-end architecture and the
rendering pipeline: multi-model decimation, draw-call batching and scene scheduling,
which held the frame rate at a stable 60 FPS and cut rendering delays by up to 15
seconds under stress testing.

**AIGC Technical Capability Platform** · Nuxt SSR · Vue 3 · Tailwind · Pinia
An enterprise platform exposing Python AI algorithms to non-technical teams. Moved the
stack to Nuxt SSR to fix the SEO problem the SPA version had, and integrated live
algorithm output over WebRTC and RTMP with Socket.io heartbeat monitoring.

**Online Creative Platform — 2D Canvas editor** · Fabric.js · Pixi.js · Anime.js · SVG
A browser design editor: drag-and-drop, real-time transforms, anti-collision detection,
movement locks, custom Pixi shaders, and Sketch-to-PNG/SVG export pipelines.

**Cross-platform customer service client** · Electron · Vue
Desktop client for a luxury e-commerce operation, shipped across Windows and macOS,
with Alipay and WeChat Pay integration on the web side.
